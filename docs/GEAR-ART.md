# Gear illustrations

Replaced abstract shaft-axis sketches with original shaded gear illustrations, displayed directly within each matching family card. A “Look for” caption connects visible tooth shape with the gear description. These are recognition illustrations, not dimensionally specified manufacturing drawings.

Asset: `dist/assets/gear-families.png`. Generated with the built-in image-generation tool. The page uses viewports into the locally saved plate; no network image dependency or raster editing script is required.

Generation prompt and targeted correction are recorded in `GEAR-ART-PROMPT.txt`.
